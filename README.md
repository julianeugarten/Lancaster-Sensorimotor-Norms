# Lancaster-Sensorimotor-Norms

This repository contains code and analysis applying the [Lancaster Sensorimotor Norms](https://www.lancaster.ac.uk/psychology/lsnorms/) (Lynott et al. 2019) to the [MythFic Corpus](https://data.ru.nl/collections/ru/rich/mythfic_metadata_dsc_550) (Neugarten 2023) of fanfiction about Greek myth and comparing it to the [Chicago Corpus](https://aclanthology.org/2024.lrec-main.71/) (Bizzoni et al. 2024) of published fiction.
